# Credits & Open Source Attributions

Development Priority Intelligence is designed as a **Digital Public Good (DPG)** and utilizes open-source libraries and open public datasets.

## Software Libraries & Frameworks
- **FastAPI**: Modern, high-performance web framework for Python (MIT License).
- **Google GenAI SDK**: Client library for interacting with Google Gemini API models.
- **Leaflet.js**: Lightweight open-source mapping library for mobile-friendly interactive maps (BSD 2-Clause License).
- **OpenStreetMap**: Map tiles and geographical coordinates provider (ODbL License).
- **Pydantic**: Data validation and settings management using Python type hints (MIT License).
- **Uvicorn**: Lightning-fast ASGI server implementation (BSD 3-Clause License).

## Data Sources & Government Portals
- **Open Government Data (OGD) Platform India (data.gov.in)**:
  - *National Hospital Directory with Geo Code*
  - *All India Health Centres Directory (PHCs, CHCs, Sub-Centres)*
  - *PMGSY Rural Road Connectivity Datasets*
- **National Family Health Survey (NFHS-5, 2019-21)**: Ministry of Health and Family Welfare (MoHFW) & IIPS Mumbai.
- **Office of the Registrar General & Census Commissioner, India**: 2011 Census baseline demographics.
- **Ministry of Jal Shakti**: Jal Jeevan Mission Har Ghar Jal dashboard indicators.
- **Ministry of Education**: Unified District Information System for Education Plus (UDISE+).

All data usage adheres to the National Data Sharing and Accessibility Policy (NDSAP) of the Government of India.
